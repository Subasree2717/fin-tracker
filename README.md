# 💸 Fin Tracker

**Fin Tracker** is a personal expense tracking web application built with [Streamlit](https://streamlit.io/). It allows users to log daily expenses, view summaries by time period, monitor eco-friendly spending, filter records, and download reports as PDFs. It encourages sustainable living by offering green financial tips.

---

## 🌟 Features

- 🔐 User authentication (login & registration)
- ➕ Add expenses with date, category, eco-friendly flag, and description
- 📊 Summarize expenses by **week**, **month**, or **year**
- 📈 Visual charts: Category-wise bars & daily trends
- ♻️ Sustainability tips to reduce waste and promote eco choices
- 📁 View and filter all records
- 📥 Export filtered records to PDF
- 🌗 Light/Dark theme toggle
